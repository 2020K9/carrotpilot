# K9 브레이크 3번 추가 제동 시작 속도 변경

2026-11-11 대감님 요청: 3번의 계속 제동을 더하는 시작 속도를 1.0에서 1.5 km/h로 변경.

- 3번(kind 18)만 `vEgo <= 1.5 / 3.6`에서 기존 추가 제동 조건을 검사한다.
- 실제 감속이 기준보다 부족할 때만 기존 속도로 제동을 추가한다. 증가량·최대치·정차 유지·StopReq·페달/고장 해제 조건은 변경하지 않는다.
- 0·1·2번, 메뉴 번호, 격차 보정의 50%/100% 전환은 그대로다.
- 1.5 km/h 초과에서 이미 감속이 정체되면 새 추가 제동 구간에 도달하지 못할 가능성은 남는다. 이 변경은 실차 문제 해결을 보증하지 않는다.

## 검증

동일 Python 환경, 실제 CarController/CAN 인코딩을 쓰는 합성 입력 시험이다. 차량 동역학 재현이나 실차 검증이 아니다.

- 직전 원격판 f7e77539: 확장 K9 시험 491 통과, 19 실패, 211 오류.
- 변경판: 같은 시험 + 신규 25건, 516 통과, 19 실패, 211 오류. 실패/오류 시험 이름 집합 동일, 신규 실패 없음.
- 신규 25건: 미설정·0·1·2번 각각 5개 시퀀스 CAN 바이트 동등성 20건, 1.5 km/h 경계 위/같음/아래 3건, 추가 제동 상한·해제 1건, 충분한 감속 시 미증가 1건.
- 기존 3번 경계 시험 입력: 미작동 0.3 → 0.42 m/s, 작동 0.27 → 1.5/3.6 m/s. 증가량·해제 assertion(검사 조건)은 유지.
- 기존 과거 기준판 비교의 환경 차단 검사는 수정/약화하지 않았다. 해당 오류와 기존 실패를 통과로 처리하지 않는다. 전체 시험 통과 아님.
- 작업 사본은 분리된 worktree(작업 트리), 워커 k9bot 자원 한도 내 실행. 네이티브 params 모듈은 직전판 기존 빌드 사본 재사용.
- 차량 접속·설정 변경·설치·재시작 없음. 원본 로그·공유 작업 사본 변경 없음.
